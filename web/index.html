NeuroTrader — Reactive Meets AI

A tiny neural network that lives inside a Reactive contract and trades on what it sees. Built for the Reactive Omni Buildathon (DoraHacks) — track: Reactive Meets AI, deadline 5 Dec 2026.

Prize pool $5,500 in REACT AI track $1,000 first place Origin Base Sepolia Reactive Lasna testnet Model 3 → 4 → 1 MLP, on-chain

The loop

PriceOracleBase Sepolia · emits PriceUpdate
→
NeuroTraderReactiveLasna · subscribes, runs the NN
→
TradeExecutorBase Sepolia · callback, paper portfolio

Every price event flows through Reactive: the oracle emits PriceUpdate on Base Sepolia, the reactive contract on Lasna receives it in react(), updates an 8-price window, runs the frozen neural network on-chain, and when the model is confident it requests a callback that lands on the TradeExecutor — which opens/closes a paper long and banks realized PnL. No off-chain bot, no paid API.

The oracle is a demo feed (a stand-in for Chainlink / Uniswap TWAP). The reactive contract subscribes by event signature, so pointing it at a real feed is a one-line constructor change.

The model — it runs inside the contract

A 3 → 4 → 1 multilayer perceptron, activation φ(x) = x / (1 + |x|), all fixed-point (1e18). Features from the last 8 prices (p0 = newest): 1-step return ×10, 5-step return ×10, and window volatility ×10. Decision: score ≥ +0.25 → BUY, ≤ −0.25 → SELL, else HOLD. Cooldown of 3 price updates and no repeated same-side trades.

Trained offline on synthetic price paths with momentum regimes (pure Python, seed 1337). On fresh synthetic data (seed 999, 25,200 windows): 77.3% accuracy at |score| ≥ 0.25 (vs 50% random), 48.8% coverage; raw sign accuracy 71.2%. Weights are frozen in NeuroNet.sol and verified bit-exact against the integer reference (ref_vectors.py) by the Foundry tests.

Full model card: MODEL.md. This is a demo model trained on synthetic data — not financial advice, and it trades a paper portfolio only.
